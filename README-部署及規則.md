# Master Trade System V1.29.1｜Record Image Lightbox

## 紀錄庫圖片放大

紀錄庫打開任何有Chart Screenshot嘅紀錄後：

- 點擊縮圖即可全螢幕放大
- 點背景可關閉
- 點右上角 × 可關閉
- 按 Esc 可關閉
- 多張圖片各自都可以點擊放大

原本下載、移除、編輯圖片功能全部保留。

## 相容性

- 圖片仍然保存喺原有IndexedDB
- 冇改圖片壓縮／儲存格式
- CSV維持149欄
- LocalStorage key不變
- Matrix、Route、P/Q、E/E+、Obstacle、Trade Objective全部不變
