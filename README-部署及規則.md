# Master Trade System V1.26.6｜P1順風恢復為獨立逆主判P2資格

## 正式規則

當交易係：

> 順次判、逆主判  
> ＋有效位置P2／合格P2-effective  
> ＋Entry-time Q3

逆主判P2可以透過以下其中一條資格取得最高0.25注。

### P1順風路徑

> 價格觸及真正P1大位  
> → 第一段真實反應仍然新鮮  
> → P1順風仍有效  
> → P2／P2-effective＋Q3  
> → 最高0.25注

P1順風路徑適用於：

- 健康主判
- 弱主判

弱主判唔再被迫只可以揀路徑A或路徑B。

### 路徑A｜主判次結首次Retest

> 弱主判  
> → 主判次結／工作結構逆向有效突破＋Acceptance  
> → 第一次Retest  
> → P2／P2-effective＋Q3  
> → 最高0.25注

### 路徑B｜健康次判＋新Session獨立確認

> 弱主判  
> → 主判工作結構突破後未Reclaim  
> → 次判已係健康反方向趨勢  
> → 全新、獨立高質Session Setup  
> → P2／P2-effective＋Q3  
> → 主判主結／第一硬障礙至少1.5R  
> → 未到成熟腿尾，亦未貼近主判主結  
> → 最高0.25注

## 三條資格關係

P1順風、路徑A、路徑B係：

> 任一成立即可

唔係累積計分。

即使同時符合兩條或三條：

> 最終仍然最高0.25注，永遠唔升到0.5。

## P1順風限制

P1順風仍然只適用於價格觸及P1後嘅第一段新鮮反應。

以下情況失效：

- 已完成一段有效回調
- 次判已正式確認新趨勢並完成結構循環
- 冇形成LH／HL而進入橫行
- P1被反覆測試消耗
- P1位置被重新Reclaim並Acceptance

P1順風只提供方向／注碼資格：

- 唔會將P2升做P1
- 唔會將Q2升做Q3
- 唔會救P4
- 唔會推翻障礙及R:R限制
- Q2固定0注

## App介面

Rulebook：

- 上方P1順風揀「有｜仍有效」後，App會自動優先判定。
- 弱主判下，路徑A／B選單會暫停，避免重複計分。
- P1順風失效或選「冇」時，先重新開放路徑A／B。

Live Decision：

- 新增「P1順風｜健康／弱主判均適用」。
- 必須同時將上方P1順風設為仍有效。
- P2／P2-effective＋Q3先會輸出0.25。

## 其他功能保留

- EU-B／EU-D專屬分類
- EU-D P3→P2-effective
- 紀錄庫批量刪除
- 119欄CSV及舊CSV兼容匯入
- 原有LocalStorage及圖片IndexedDB
