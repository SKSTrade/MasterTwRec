# Master Trade System V1.30.3
## Record Library Sorting

紀錄庫新增「排序」：

- 紀錄時間｜最新 → 最舊
- 紀錄時間｜最舊 → 最新
- 入場／交易日期｜最早 → 最新
- 入場／交易日期｜最新 → 最早
- 紀錄編號｜#1 → #N
- 紀錄編號｜#N → #1
- 商品｜A → Z

排序可以同現有Filter一齊使用：
- Practice / Live
- Entry / Miss / Skip
- 商品
- 日期範圍

紀錄編號仍然係按全紀錄庫建立時間計算，排序只改畫面次序，唔會改record number。

「清除篩選」只清除Filter，唔會改你揀咗嘅排序方式。

Frozen V1.3 Matrix、Trade Objective、Shadow Research、CSV schema、圖片DB、LocalStorage全部不變。
