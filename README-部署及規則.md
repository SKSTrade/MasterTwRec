# Master Trade System V1.26.7｜紀錄視窗點擊外圍關閉

## V1.26.7新增功能

喺「紀錄庫」打開其中一筆紀錄後：

> 點擊小視窗外面嘅灰色遮罩／空白位置  
> → 關閉紀錄小視窗

行為限制：

- 點擊小視窗內部唔會關閉
- 小視窗內滾動唔會關閉
- 編輯欄位、圖片下載、圖片移除及按鈕操作唔會誤關
- 原有右上角×、取消按鈕及Esc關閉保持不變
- 點擊外圍等同取消，未按「儲存修改」嘅變更唔會保存
- 關閉後會沿用原有圖片暫存清理流程

## V1.26.6規則保留

逆主判P2資格仍然有三條獨立路徑：

1. P1順風｜健康／弱主判均適用
2. 路徑A｜弱主判次結突破＋首次Retest
3. 路徑B｜健康逆向次判＋新Session獨立確認

全部只限P2／P2-effective＋Q3，最高0.25；多條同時成立唔疊加。

- EU-D P3→P2-effective

- 119欄CSV及舊CSV兼容匯入
